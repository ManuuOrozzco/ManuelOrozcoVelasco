## 🎯 Mi enfoque
Diseño apps pensando primero en la persona que las usa:
- **Intuitivas:** interfaces claras que se entienden sin tutoriales , onboarding en menos de 20 segundos.
- **Simples:** cada pantalla tiene un objetivo, sin elementos que sobren.
- **Accesibles:** pensadas para todo tipo de usuarios, con curva de aprendizaje mínima.
